# Introduction
Aplicación Web MVC Demo de Control de Clientes con Java + Spring Boot Framework.

Se creó siguiendo el curso [Universidad Java en Udemy](https://www.udemy.com/course/universidad-java-especialista-en-java-desde-cero-a-master/).

# Getting Started

## Dependencies
- Java v24
- Maven
- Spring Boot 4.0.0-RC2
- Spring Security
- Spring Data + JPA
- Thymeleaf + Thymeleaf Security
- Lombok
- MySQL Connector
- Bootstrap 5.3.8 (CDN)
- Font Awesome 7.0.1

## Features
- Arquitectura con separación de responsabilidades.
- Autenticación y Autorización de usuarios.
- Cifrado de contraseñas con BCryptPasswordEncoder.
- CRUD de Clientes.
- Validación de Formularios.
- Uso de ventanas modales.
- Manejo de errores y excepciones.
- Manejo de propiedades.
- Mensajes e Internacionalización (ES/EN).
- Cambio de tema (Claro/Oscuro).
